# UI/UX QA: every screen, 2026-10-23

Claude Code did this QA after design language v2 landed. The build tested was the mock dev server (`npm run dev:mock`, port 5174) on branch `feat/frontend-redesign`, **including Codex's uncommitted working tree** at the time.

**How:**
- Claude's built-in browser pane, signed in as all four demo roles.
- Headless real Chrome for screenshots, used once the pane was hidden.
- An in-page audit on every route: horizontal overflow, unlabeled controls, tap targets under 36px on phones, heading structure, asymmetric radii, glass on reading surfaces, and console errors.
- Sizes: 1440×900 and 375×812 for every route. The patient pages were also checked at 1280×620, 1536×730 and 1920×960 earlier today.

**Overall:**
- No route overflows horizontally at any size.
- No unlabeled buttons. Fonts are Fraunces and Inter only, with no leftover Jakarta.
- Form validation is solid where it exists: household, appointments, consult, payment and code lookup all show inline errors, focus the first invalid field, and catch future dates and whitespace-only input.
- The problems are mostly **UX structure and copy**, plus three real bugs (all fixed).

Severity: **S1** crash or wrong data · **S2** blocks or misleads a user · **S3** visible quality problem · **S4** polish.

## Claude's polish items (fixed 2026-10-27)

| # | Sev | Screen | Finding | Fix |
|---|---|---|---|---|
| M1 | S3 | Public nav over the dark bands | The glass pill turned grey over `ground` bands, so the nav text lost contrast. | `glass-strong` is now white 92% with saturate 140% (the tab bar and top bar get the same lift). |
| M2 | S3 | Landing (phone) | Footer links, bento card links and the footer logo were 17–28px tall. | They're 40px on phones now (footer links are 32px on desktop, for a mouse). No link under 40px at 375. |

| M4 | S3 | Payment, waiting state | A small card on an empty canvas, a reference you couldn't copy, and no sign of progress until the timeout. | The waiting screen is now main + aside: elapsed-time bar against the 2-minute window, three steps (sent, approve, queue), the order summary, and a copyable reference (also on "Payment received"). `StatusMark` and `PageSpinner` lost their v1 morphing/rotation; the spinner waits 300ms before showing. |
| M5 | S4 | Sign-in → role shells | An empty frame between picking a role and the new shell. | **Cause found; it's in `SignIn.tsx` (Codex).** Production build: ~0.1s gap on a fast connection, up to 2.3s on a throttled one.
